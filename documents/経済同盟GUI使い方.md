## 概要

BSM経済同盟システムは、国家間の経済的協力関係を管理するカスタムGUIシステムです。
軍事同盟（陣営）とは独立して動作し、**1カ国が複数の経済同盟に同時加盟**できるのが特徴です。

| 機能 | 説明 |
|------|------|
| 陣営作成 | 盟主として新たな経済圏を結成 |
| 加盟 | 既存の経済圏に参加 |
| 目標設定 | 陣営の統合段階を段階的に引き上げる |
| アクション | ODA・融資・技術支援など加盟国への経済支援 |
| 投票 | 民主制運営時の目標決定投票 |
| ランキング | 世界全陣営の国力順位を表示 |

---

## GUIの開き方

1. **政治画面**（`countrypoliticsview`）を開く
2. 画面左下に表示される **「経済同盟」** ボタンをクリック
3. ウィンドウが開く。もう一度クリックすると閉じる

> ウィンドウは移動可能（`moveable = yes`）。ESCキーでも閉じられます。

## 所属同盟リスト

ウィンドウ上部に、**プレイヤーが現在所属している全経済同盟**の一覧が表示されます。

| 表示項目 | 内容 |
|----------|------|
| 同盟名 | `[国名]経済圏`（カスタム名設定時はそちらを優先） |
| メンバー数 | 加盟国の数 |
| 国力 | 陣営合計国力（工場数またはUC月収ベース） |

- **同盟をクリック**すると、その陣営の詳細（加盟国リスト・目標・ステータス）が下段に表示される
- **`[<]` / `[>]` ボタン**で複数陣営を切り替え（2つ以上加盟している場合に表示）

> **未加盟の場合:** 「どの経済同盟にも加盟していません」と表示されます。

## 加盟国リスト・ステータス

選択中の陣営の加盟国一覧と、陣営の現在の状態を表示します。

### 成熟度（Maturity）

成熟度はメンバー数と信頼度によって自動計算されます（月次更新）。

| 成熟度 | 条件 |
|--------|------|
| 1 | 初期状態（陣営作成直後） |
| 2 | メンバー2カ国以上、または高信頼国1カ国以上 |
| 3 | メンバー4カ国以上、または高信頼国2カ国以上 |
| 4 | メンバー6カ国以上、または高信頼国3カ国以上 |
| 5 | メンバー8カ国以上、または高信頼国5カ国以上 |

> **高信頼国（High Trust）:** `bsm_ea_trust > 29`（信頼度30以上）の加盟国

### 運営モード（盟主のみ変更可）

| モード | 説明 |
|--------|------|
| 盟主主導 | 盟主が目標を即座に設定できる |
| 共同運営 | 目標設定は加盟国全体の投票で決定 |

---

## 同盟目標システム

目標は成熟度に応じて段階的に解放されます。**盟主のみ設定可能**です。

| 目標 | 必要成熟度 | 効果（アイデア） |
|------|-----------|------------------|
| 地域経済協力 | 1以上 | `bsm_ea_goal_01_cooperation` |
| 関税同盟 | 2以上 | `bsm_ea_goal_02_tariff` |
| 通貨同盟 | 3以上 | `bsm_ea_goal_03_currency` |
| 共通市場 | 4以上 | `bsm_ea_goal_04_market` |
| 完全経済統合 | 5以上 | `bsm_ea_goal_05_union` |

### 目標の設定手順

1. **盟主主導モード:** ウィンドウ下部「設定可能」欄のボタンをクリック → 即時全加盟国に適用
2. **共同運営モード:** ボタンをクリック → 30日間の投票が開始される

> 既にアクティブな目標は「設定可能」欄に表示されません（重複適用なし）。

---

## 投票システム

**共同運営モード**で目標を提案すると、全加盟国による投票が始まります。

### 投票の流れ

```
1. 盟主が目標ボタンをクリック
      ↓
2. 投票が開始（30日間）
   - AI国は盟主への好感度に応じて自動投票
   - 好感度 > 30 → 賛成
   - 好感度 < -10 → 反対
   - それ以外 → 棄権
      ↓
3. プレイヤーが [賛成] / [反対] / [棄権] をクリック
      ↓
4. 30日後、集計（過半数賛成で可決）
   - 可決: 目標が全加盟国に適用される
   - 否決: 何も起こらない
```

### 投票状況表示

| 表示 | 内容 |
|------|------|
| 残り: N日 | 投票期間の残り日数 |
| 賛成 / 反対 / 棄権 | 現在の得票数 |

> 既に投票済みの場合、再クリックで票を変更できます（まず前の票がリセットされます）。

## 加盟国アクション

**同じ陣営の加盟国**に対して、経済支援アクションを実行できます。

### ターゲットの選択

1. 「加盟国アクション」セクションのリスト（同陣営メンバー一覧）から国をクリック
2. 「対象:」欄に選択した国名が表示される
3. 各アクションボタンが有効化される（条件を満たした場合）

### アクション一覧

| アクション | コスト | 効果 | クールダウン |
|------------|--------|------|-------------|
| ODA | UC 50 | 対象に UC+50、安定度+1%、関係改善 | 90日 |
| 長期融資 | UC 100 | 対象に UC+200、対象PP -30 | 180日 |
| 短期融資 | UC 200 | 対象に UC+400、対象PP -50 | 90日 |
| 負債肩代わり | UC 300 | 対象PP +100、安定度+3%、脱退ペナルティ解除 | 365日 |
| インフラ投資 | UC 150 | 対象に UC+100、安定度+2%、戦意+1% | 180日 |
| 技術支援 | UC 250 | 対象に UC+100、安定度+2%、PP +50 | 365日 |

> **UC（統一通貨）** = `Unified_Currency` 変数。不足している場合はボタンがグレーアウトします。

### アクションボタンの有効化条件

以下をすべて満たす必要があります：

- ターゲットが選択されている（`bsm_ea_has_selected_member = 1`）
- 手持ちUCがコスト以上ある
- クールダウンが残っていない（`bsm_ea_cd_xxx = 0`）

## 経済同盟を離脱する

1. ウィンドウ上部のリストで**離脱したい同盟を選択**
2. 「経済同盟を離脱」ボタンをクリック

### 離脱時の処理

- 全加盟国との関係改善修正値（`bsm_economic_alliance_relation_boost`）が削除される
- `recently_left_economic_alliance` アイデアが365日間付与される（再加盟不可）
- 政治力 -50
- **盟主が離脱した場合:** 次のメンバー（配列index 1）が自動的に新盟主になる
- **最後の1人が離脱した場合:** 陣営が解散する

> **注意:** 離脱前に必ず対象陣営をリストで選択してください。選択せずに離脱すると主要所属陣営から離脱します。

## 世界ランキング

ウィンドウ下部に、**全経済同盟の国力ランキング**が表示されます。

| 列 | 内容 |
|----|------|
| 順位 | 国力降順のランク（週次更新） |
| 同盟（盟主） | 同盟名と盟主国 |
| 総合国力 | 全加盟国の国力合計 |

### 国力の計算式

```
国力 = Unified_Currency_Last_Month_gain ÷ 10
（月収データがない場合: 民間工場数 + 軍事工場数）
```

ランキングは毎週自動更新されます（`on_weekly`）。

## 経済同盟の結成・加盟（ディシジョン）

GUIウィンドウ外から経済同盟を操作するには**ディシジョン**を使います。

### 経済同盟を結成する

**ディシジョン:** `bsm_form_economic_alliance`
**対象:** 隣接国（`target_array = neighbors`）

| 条件 | 内容 |
|------|------|
| 政治力 | 100以上 |
| 統一通貨 | 100以上 |
| 対象国の好感度 | 25以上 |
| 内戦中でない | ✓ |
| 対象国と戦争中でない | ✓ |

**コスト:** 政治力 -100、統一通貨 -100

### 経済同盟に加盟する

**ディシジョン:** `bsm_join_economic_alliance`
**対象:** 盟主国（隣接の盟主国を自動検出）

| 条件 | 内容 |
|------|------|
| 政治力 | 10以上 |
| 統一通貨 | 25以上 |
| 対象盟主の好感度 | 25以上 |
| 脱退後クールダウン中でない | ✓ |

**コスト:** 政治力 -10、統一通貨 -25

## スクリプトから直接呼び出す

### 陣営の作成（イベント・エフェクトから）

```paradoxscript
# 盟主国のスコープで実行
bsm_ea_generate_new_token = yes   # 新しいトークン(ID)を生成
bsm_ea_create_sphere = yes        # 陣営を作成
```

### 陣営への加盟

```paradoxscript
# 加盟国スコープで実行
# bsm_ea_token を事前に設定（盟主の bsm_ea_sphere 変数から取得）
set_temp_variable = { bsm_ea_token = FROM.bsm_ea_sphere }
bsm_ea_join_sphere = yes
```

### 陣営からの離脱

```paradoxscript
# 離脱国スコープで実行
set_temp_variable = { bsm_ea_token = var:bsm_ea_sphere }
bsm_ea_leave_sphere = yes
```

### GUIデータの手動更新

```paradoxscript
# プレイヤースコープで実行（ウィンドウを再描画）
bsm_update_ea_gui_data = yes
```

### 既存陣営へのメンバー追加（初期化用）

```paradoxscript
# 加盟国スコープで実行（bsm_ea_sphere = 盟主の陣営トークン）
bsm_ea_init_add_member = yes
```

## クールダウン一覧

各アクションの変数名と冷却期間。

| 変数 | アクション | 日数 |
|------|------------|------|
| `bsm_ea_cd_oda` | ODA | 90日 |
| `bsm_ea_cd_loan_long` | 長期融資 | 180日 |
| `bsm_ea_cd_loan_short` | 短期融資 | 90日 |
| `bsm_ea_cd_debt_relief` | 負債肩代わり | 365日 |
| `bsm_ea_cd_infra` | インフラ投資 | 180日 |
| `bsm_ea_cd_tech` | 技術支援 | 365日 |

クールダウンは**月次更新**（`on_monthly`）で30ずつ減算されます。
デバッグ時に手動リセットする場合：

```paradoxscript
set_variable = { bsm_ea_cd_oda = 0 }
set_variable = { bsm_ea_cd_loan_long = 0 }
# ... 他も同様
```

## よくある問題

### Q. GUIを開いてもリストが空になる

**原因:** `on_startup` での初期化が実行されていない可能性があります。
**対処:** テストディシジョン「初期化フラグをクリア」→「初期経済圏を手動作成」を順に実行してください。

### Q. アクションボタンがグレーアウトして押せない

**原因:** 以下のいずれか:
1. ターゲット国が選択されていない
2. UCが不足している
3. クールダウン中

**対処:** 加盟国リストから国をクリックしてターゲットを選択し、UCとクールダウンを確認してください。

### Q. 目標ボタンが表示されない

**原因:** 以下のいずれか:
1. プレイヤーが選択中の陣営の盟主でない
2. 成熟度が目標の必要値に達していない
3. 目標がすでにアクティブ

**対処:** 盟主国でプレイし、陣営の成熟度を上げてください。

### Q. 離脱後すぐに再加盟できない

**原因:** 離脱時に `recently_left_economic_alliance` アイデアが付与され、365日間は再加盟がブロックされます。
**対処:** テスト時はデバッグディシジョン「負債肩代わり」アクションでアイデアを除去するか、コンソールで `remove_ideas = recently_left_economic_alliance` を実行してください。

### Q. `bsm_ea_sphere` 変数が 0 のまま

**原因:** 陣営に加盟していないか、初期化が完了していません。
**対処:** `bsm_update_ea_gui_data` を実行するか、テストディシジョンで初期化してください。
