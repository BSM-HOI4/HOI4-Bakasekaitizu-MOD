# 英国のBSM移植

`feature/london_three_sovereignties` は作業開始時点で現在のdevelopに統合済み。英国本体はGBRであり、ENGという別国家へ新規コンテンツは割り当てない。

## 実装

- `uk.txt` の未移植バニラツリーを、既存のGBR企画に基づく41国家方針へ構成し直す。ツリーID `british_focus` は維持。新規IDは `GBR_bsm_*`。
- 共通5・政治16・経済6・軍事8・対外6。政治4路線と対仏協調/強硬の入口は対称排他。工業と軍事は会議の成功を前提としない。
- 外交は10件の承認/拒否イベントを用いる。主権・軍の指揮権は保持。通商協力は研究/通商の精神として実装し、合邦・共通軍AI・研究共有GUIは導入しない。
- LON予備会談は既存 `LON.30`、憲法会議は準備条件を満たしてから `LON.36` へ合流。橋への援助は市側の承認後に既存修繕effectを呼ぶ。
- 帰還案は市が共和国路線を選び、GBRの首都分散が済み、三国が平時の場合に市へ提示。市の承認後も英国の既存 `LON.44` が最終判断する。過去の結末は巻き戻さない。
- 北部協議はLONの承認後に既存 `LON.53` へ接続。領有者の承認・IRE署名を省かない。
- 未準備・拒否後の再提案は英国の決定5件（政治力25、90日間隔）。憲法会議準備を終える前に英国NFが完了しても、準備後に提案し直せる。
- 新規イベントで直接扱う領土はドーバー州835のみ。FRAが平時に所有・支配し、FRA自身が承認した場合だけGBRへ移譲する。英国側の補償は政治力75。拒否で自動開戦しない。
- 国内建設は既存州128/130/132/127の所有・支配を確認。失っている場合は国内代替報酬に切り替える。

## 保全と互換性

置換前の英国スクリプトは `uk-before-port.txt`、元日本語本文は `ENG_focus-before-port.yml` にそのまま保全。旧英国NFの有効な外部 `has_completed_focus` 参照はコメントを除外して走査し、残存0件を確認した。人物・技術・OOB・国家履歴・LON既存47イベントは変更しない。

旧バニラ方針IDの完了履歴は新規 `GBR_bsm_*` の完了へ自動変換しない。今回の移植は新規開始で検証する。既存セーブの途中NF進行・AI方針の移行は未保証。

41NF企画の各名称・構成は採用したが、帝国連邦は現段階で同意した政府間の協力協約として表現する。参加数を要件とする共通予算制度や制裁/最後通牒等は追加していない。

## 検証

- `python3 tools/verify_britain_bsm.py`: 41NFのID・配置・前提循環・排他対称、10イベントの拒否/実行条件、領土操作範囲、LON呼出し、日本語一意性・BOM。
- `python3 tools/verify_london_scenario.py`: 既存三者シナリオの構文・166日本語参照・8領土/15外交モデルケースPASS。
- 実起動は親エージェントが全体変更とまとめて実施する。上記は静的検証で、UI・方針完了操作・長期AI・セーブ互換性の実証ではない。
