# 新規参加者向けオンボーディングガイド

## プロジェクト概要をつかむ
- 「バカ世界地図」は、Chakuwiki発の共同創作企画をハーツ・オブ・アイアンIV上で再現するトータルコンバージョンModです。奇抜な国家設定や新規システムが多数実装されており、既存の世界観やゲーム体験から大きく逸脱した内容になっています。【F:README.md†L1-L27】
- プレイ/開発対象のゲームバージョンはHoI4 1.13系です。開発環境では日本語化Modとの併用が前提なので、ローカルでの動作確認時は両Modを起動セットに含めてください。【F:README.md†L29-L66】

## リポジトリ構造の全体像
- `bakasekai/` : 実際にゲームへ読み込まれる主要アセットが集約されています。`common/`（定義系）、`events/`（イベント）、`history/`（国家史）、`localisation/japanese/`（日本語ローカライズ）、`gfx/`・`interface/`（UI資産）、`map/`（地図関連）などの下位フォルダ構成を把握しておくと差分調査が捗ります。【F:AGENTS.md†L3-L4】
- `documents/00_coding_contexts/` : スクリプトで扱えるスコープやトリガー・エフェクト、変数などの参照資料。初めての処理を書くときはここを辞書的に使うと安全です。【F:AGENTS.md†L5】
- `flags/00/`〜`03/` : 国旗画像の分割保存場所。画像差し替え時は命名規則を確認してから該当シャードを編集します。【F:AGENTS.md†L6】
- `tests/` : プロトタイプや検証用シナリオの置き場。本番データに影響させず動作検証したいときに活用します。【F:AGENTS.md†L7】
- `documents/96_buildings.md` や `documents/98_country.md` といった周辺資料も、既存データの一覧や命名の整合性を調べる際に便利です。【F:documents/96_buildings.md†L1-L23】

## 作業前に押さえるべき開発ルール
- インデントはスペース2個、1行1命令が原則です。タブを使うと差分が荒れるので避けてください。【F:AGENTS.md†L14-L15】
- 国家固有ファイルは3文字タグ、システム関連は`_bsm_`接頭辞を付ける命名規則が徹底されています。既存ファイルを参考に名称を揃えましょう。【F:AGENTS.md†L16-L17】
- イデオロギーやローカライズは既存キーに合わせ、`localisation/japanese/*.yml`をUTF-8 BOM付きで管理します。キー名の揺れはバグにつながるので要注意です。【F:AGENTS.md†L18-L19】
- テスト用の追加コンテンツは`_bsm_*_test.*`など分離された命名とし、コンソールイベントでの検証やクリーンアップ処理を心掛けます。【F:AGENTS.md†L21-L24】
- プロファイラや`imgui show profiler`、`tdebug`などのデバッグコマンドを使い、処理負荷やイベント挙動を定期的に確認する運用が推奨されています。【F:AGENTS.md†L10-L12】

## 最初の学習ステップ
1. **READMEを通読し、世界観と対象バージョンを把握する。** プロジェクトの目的やプレイ要件を理解することで、開発判断の背景が掴めます。【F:README.md†L1-L66】
2. **`documents/00_coding_contexts/`の基礎資料を確認する。** 特に`effects_documentation.md`や`triggers_documentation.md`は、効果・条件を書く際のリファレンスとして必須です。【F:documents/00_coding_contexts/effects_documentation.md†L1-L24】
3. **担当領域に近い既存ファイルを読み込む。** 例：建物関連なら`documents/96_buildings.md`と`bakasekai/common/buildings/`、国家方針なら`bakasekai/common/national_focus/`を参照し、命名や構造を学びます。【F:documents/96_buildings.md†L1-L23】【F:AGENTS.md†L3-L4】
4. **ローカルでModを起動し、変更の反映手順を体験する。** Paradox LauncherでModを読み込む手順や、デバッグコマンドの使い方を習得すると作業効率が上がります。【F:README.md†L29-L66】【F:AGENTS.md†L10-L12】
5. **小さな改善タスクからPRフローを練習する。** コミットメッセージやPR本文には、対象範囲・再現/検証方法・ローカライズ差分などを明確に記載します。【F:AGENTS.md†L26-L29】

## 困ったときの相談先
- Discord開発サーバーやコミュニティサーバーで質問できます。コントリビューションの相談や翻訳依頼など、役割ごとに案内が分かれているので活用してください。【F:README.md†L74-L95】
- 翻訳協力の場合はParatranzプロジェクトが運用されているため、アカウントを作成して参加するのが最短です。【F:README.md†L80-L88】

> **TIP:** 変更内容を共有する際は、性能面の観測やテスト手順を簡潔にまとめるとレビューがスムーズになります。定期的に`tests/`やドキュメント類を活用し、知識をチーム全体で共有していきましょう。
