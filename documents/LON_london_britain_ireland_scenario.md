# ロンドン橋の向こう側 — 二つの島、三つの主権

2026-11-01実装。対象は `LON`・`GBR`・`IRE`。既存の国家タグ、市長、州の初期配置、既存5国家方針IDを保全する。初期州データ・地図・音声・実セーブは変更しない。

## 開始状況と進め方

`LON` は州113・119・134・135を支配し、首都は113。英国本体は `GBR` で、実際のロンドン州126を支配する。`IRE` は初期領土を持たず、ロンドン国内の代表会議として物語に登場した後、憲法会議で国家になる。

ロンドンで「基盤構築」→「島の住所を決める国勢調査」→「橋の修繕会議」→「三者の憲法会議」を進める。代表会議イベントの回答待ちの間は金融・英連邦外交の枝を進められる。世界投資はケルト協約に依存しない。

## 実装した進行

| 段階 | イベント | 内容 |
|---|---|---|
| 国勢調査 | LON.30–31 | 全住民を市民として課税する調査に地方議会が異議。住民代表の参加か、市の権威優先かを選ぶ |
| 代表会議 | LON.11–12 | 既存交渉イベントを国内の代表会議へ接続。交渉拒否・決裂でも次段階を塞がない |
| 修繕費 | LON.32–35 | 英国援助・市債・地方共同予算・延期。英国援助は英国側が回答し、拒否時は市債／共同予算を選び直す |
| 憲法会議 | LON.36–40 | 南西2州にIREを成立させ、IREとGBRへ順番に承認を求める。拒否には一度の対案か強硬路線で対応 |
| 決裂後 | LON.41 | IRE自身が現国境維持か対LON戦争を選ぶ |
| 独立 | LON.42–43、46–47 | LONの請願にGBRが回答。拒否後の一方的独立宣言にもGBRが容認／武力介入を選ぶ |
| ロンドン帰還 | LON.44 | 共和国路線でGBRが州126の移譲を別途判断 |
| 二つのロンドン | LON.45、48–49 | 独立した強硬派LONが州126を要求。GBRの回答後、LONが撤回／開戦を判断 |
| 個別停戦 | LON.50–52 | IRE→LON、LON→GBR、IRE→GBRの申し入れに受信国が回答 |
| 北部協議 | LON.53–55 | GBR仲介、現在の領有者の承認、IREの署名を経て州119を移譲 |
| 任意の連邦協約 | LON.18–19 | 憲法会議後にIREへ提案。受諾時は両国に協約の国民精神を付与し、国境・タグ・独立は維持 |

### 四つの結末

- **三者協約**：IRE・LON・GBRが承認。三者に通商・安定の国民精神を付与する。国家・領土は別個に維持する。
- **共和国**：まずIREが南西2州で成立。GBRが帰還案も承認した場合だけ、126→LON（首都126）、113→IRE（首都113）の順に移譲する。拒否時は現在の領土で共和国との関係を維持する。
- **シティの自治**：IREとの権限分担と市の憲章を成立させる。英国からの独立は、別の国家方針と英国の回答を経る。
- **強硬路線**：IREとの会議が決裂する。即座に戦争を強制せず、IREは武力行使を拒める。LONの対英州126要求は英国から独立した後に可能。

「連邦協約」は協力関係を表す国民精神であり、単一国家への合邦・共同外交AI・独自連邦GUIは実装していない。個別停戦はHOI4の `white_peace` を対象国へ実行するため、陣営戦争に関するエンジン側の挙動は実ゲームで確認が必要。

## 領土・同意・遅延イベント

- IRE新設はLONが平時に134・135を所有・支配し、IREが未成立の場合に限る。中核州134・135を追加して `release = IRE` した後に113へIRE中核を追加するため、解放時にLONの首都113や北部119を失わない。
- 新政府の首都は135。固有OOB `IRE_ts_guard` からコーク・ゴールウェーに各1個の守備隊を一度だけ配備する。既存IRE人物・国家履歴を利用する。
- 126の移譲はGBRが所有・支配している場合だけ。帰還時はLON中核も追加する。113の移譲もLONの所有・支配が必要。英国などの既存中核は削除しない。
- 北部119は憲法会議や帰還の一括取引に含めない。三国が平時で、GBRまたはLONが所有・支配して同意した場合だけ、IREの最終署名で移譲する。第三国の所有・占領を奪わない。
- 危険な移譲・開戦は選択肢の表示条件に加え、選択効果の実行時にも再確認する。会議の結末は一度だけ適用する。
- 新規回答イベントは14日の回答期限を持つ。NF終了からイベント発生までに情勢が変わった場合は、憲法会議準備の再開・会議再招集・独立再申請の決定を使える。

## 既存機構への修正

- 橋：損耗100から既存崩落イベントへ接続。損耗による障害精神、修理による障害解除、損耗0で橋存在フラグを復元。修理の政治力二重徴収と一時変数参照を修正する。
- 大修理：工場を減算して後で返す処理を、90日間の修繕負担精神に置換する。橋は変数・経済効果であり、地図の陸上接続を変更しない。
- 投資：相手の受諾フラグがある場合だけ期限後の投資報酬を付与。拒否しても報酬が付く経路を閉じる。投資カテゴリ参照を実際の既存カテゴリに合わせる。
- 銀行危機：既存の世界危機フラグからLON.17へ自動発火を接続し、一度だけ発生させる。第一段階で不況精神を除去した後も第二段階へ進める条件に直す。
- 既存LON.13は互換用の入口として残し、英国側が回答する独立請願へ接続する。既存5国家方針の日本語キーは保全し、新規キーを別ファイルへ重複定義しない。既存localisationの重複整理は行っていない。

## 検証

実行コマンド：`python3 tools/verify_london_scenario.py`

この検査は実装テキストを構文木として読み、イベントID・呼出し・scripted effect／idea参照、日本語BOM／新規キーの一意性、NF依存・座標・循環、trigger/effect境界を検査する。限定モデルでは実際のeffectを評価し、正常解放・再実行・第三国所有／占領・戦時・四結末の承認・北部移譲・停戦対象を確認する。モデルはHOI4エンジンの代替ではない。

実測結果・対象ファイルのハッシュは `documents/verification/london-three-sovereignties-2026-11-01/` を参照。

### 実ゲームで残る確認

1. 1936年新規開始でLONを選び、上記4段階をNFから進める。代表会議の承認・拒否双方から橋へ進めることを確認する。
2. 憲法会議直前に**検証用の別セーブ**を作り、四結末を個別に確認する。IRE誕生後もLONを継続操作でき、IREの首都・守備隊が正常なことを見る。
3. 共和国路線で `tag GBR` により英国の回答を操作し、126受諾／拒否を比較する。英国が別戦争に入った場合に移譲できないことを見る。
4. 強硬路線でIREの武力行使、独立請願の拒否後のLON宣言、GBRの介入、各停戦回答を確認する。陣営参加時の停戦波及は特に確認する。
5. 北部のGBR領／LON領それぞれで三段階の承認・拒否を試す。回答途中で戦争や占領が起きた場合にも移譲しないことを見る。
6. 橋の崩落→大修理→小修理→再表示、投資の受諾／拒否→期限経過を確認する。NFツリーの実画面配置、セーブ再読込、AI長期進行も確認する。

イベント単体の入口確認には `event LON.30 LON` を使える。ただしコンソールによる単体発火は通常進行やAI検証の代わりにはならない。
