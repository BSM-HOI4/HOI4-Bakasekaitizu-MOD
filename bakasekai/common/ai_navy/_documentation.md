# 目標ベースの海軍AI (Goal-based Naval AI)

## はじめに (Introduction)

このシステムは、AIが任務（ミッション）を遂行する方法を置き換えるものです。以前のシステムは、任務間の事前定義された優先順位と、任務部隊（Task forces）を集めて任務に割り当てる際のやや不明瞭なロジックに依存していました。この新しいシステムは、AIの意思決定プロセスをより柔軟で、理解しやすく、スクリプト（記述）しやすくすることを目的としています。

## 重要な概念 (Key concepts)：

### ゴール (Goals)

「ゴール」とは、AIが海軍を利用して行う可能性のある、高レベルな作戦行動のことです。

例:
* 上陸作戦（Naval invasions）の支援
* 通商路（Trade routes）の保護
* 制海権（Naval dominance）の確立

ゴールは「行動」と「目的」を包含しますが、ゴール自体には特定のターゲットが存在しません。そこで登場するのが オブジェクティブ（Objectives） です。

### オブジェクティブ (Objectives)

「オブジェクティブ」とは、特定のターゲットに対して「ゴール」を適用したものです。

例:
* **硫黄島**での上陸作戦支援（つまり、特定の侵攻作戦）
* **フランス**との通商路保護（つまり、特定の交易ルート）
* **地中海**での制海権確立（つまり、特定の海域）

## ゴールとオブジェクティブのスコアリング (Goal/Objective Scoring)

ある国家のすべてのアクティブなオブジェクティブが収集され、スコア付けされます。その後、スコアに応じた優先順位でオブジェクティブが実行されます。AIは最もスコアの高いものから順に、可能な限り多くのオブジェクティブを実行しようとします。

オブジェクティブは、以下の2つの要素に基づいてスコアリングされます。
* ゴール優先度 (The goal priority): 
各ゴールには優先度の範囲（レンジ）があり、そのゴールがその国にとってどれほど重要かを示します。この範囲によって、そのゴール内のオブジェクティブが取り得るスコアの範囲が決まります。

* オブジェクティブ重要度 (The objective importance): 
これは0～1の間の正規化された値で、ゴール優先度の範囲内のどこにそのオブジェクティブが位置づけられるか（スコア付けされるか）を決定します。

### 例:

* 上陸支援 (Naval invasion support) ゴールの優先度範囲は5～10です。
  * 硫黄島を対象とするオブジェクティブがあり、重要度は0.8です。
  * 沖縄を対象とするオブジェクティブがあり、重要度は0.4です。

* 船団護衛 (Convoy protection) ゴールの優先度範囲は3～8です。
  * フランスとの通商路を対象とするオブジェクティブがあり、重要度は .9です。
  * スペインとの通商路を対象とするオブジェクティブがあり、重要度は0.4です。

AIはこれらのオブジェクティブを以下のようにスコアリングします：
* 硫黄島での上陸支援： 9.0 ( 5 + (10-5) * 0.8 )
* フランスとの船団護衛： 7.5 ( 3 + (8-3) * 0.9 )
* 沖縄での上陸支援： 7.0 ( 5 + (10-5) * 0.4 )
* スペインとの船団護衛： 5.0 ( 3 + (8-3) * 0.4 )

図示されたように、この結果、異なるゴール由来のオブジェクティブが入り混じった優先順位となります。この考え方は、ゴール優先度によって最も関連性の高いゴールが常に優遇されるようにしつつ、オブジェクティブ重要度によってゴール内での優先順位を決定するというものです。また、このシステムにより、上記の例で見られるように、優先度の低いゴールの「高価値なオブジェクティブ」が、優先度の高いゴールの「低価値なオブジェクティブ」よりも優先されるチャンスが生まれます。

## スクリプティング (Scripting)

```
goal_name = {
    objective_type = [type] # 下記の「オブジェクティブの種類」を参照
    available_for = {
        ENG # これが記述されている場合、そのゴールはデフォルトで全国家無効となり、このブロック内の国家でのみ有効になります
    }
    blocked_for = {
        GER # これが記述されている場合、そのゴールはこのブロック内の国家では無効になります
    }
    
    min_priority = 5 # このゴールの最小優先度。上記の「ゴール/オブジェクティブのスコアリング」を参照
    max_priority = 10 # このゴールの最大優先度。上記の「ゴール/オブジェクティブのスコアリング」を参照
}
```

### オブジェクティブの種類 (Objective Types)

以下のオブジェクティブタイプがサポートされています：
* naval_invasion_support（上陸支援）
* naval_invasion_defense（上陸防衛）
* mines_sweeping（掃海／機雷除去）
* coast_defense（沿岸防衛）
* convoy_protection（船団護衛）
* convoy_raiding（通商破壊／船団襲撃）

## Debugging
コマンド "imgui show ai_navy" を使用すると、海軍のゴールのデバッグ表示を有効にできます。
